# RobotEyes pour Pico-Oled-Boot

RoboEyes utilise un FrameBuffer pour dessiner et animer des yeux sur un écran.

Roboyes pour Pico-Oled-Boot dispose de scripts d'exemples dans [examples/roboeyes/](examples/roboyeyes/) .

# Exemples

* __[roboeyes_basic.py](roboeyes_basic.py)__ : script élémentaire montrant comment mettre un RoboEyes en place.
* __[roboeyes_interactive.py](roboeyes_interactive.py)__ : script utilisant le joystick pour modifier les caractéristiques du RoboEyes.
* __[roboeyes_sequence.py](roboeyes_sequence.py)__ : script mettant en place une séquence animée RoboEyes.
