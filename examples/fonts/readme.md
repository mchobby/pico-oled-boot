# Pico-Oled-Boot et Fonts FBGFX

Grâce à la bibliothèque FBGFX incluse avec Pico-Oled-Boot, une script peut
charger une Font alternative et l'utiliser pour dessiner du texte avec la
la classe FBText de FBGFX.

Ce répertoire d'exemple contient des scripts indiquant comment charger et
utiliser de telles Fonts.

Plus de font peuvent être retrouvée depuis la bibliothèque FBGFX:

* [FBGFX/lib](https://github.com/mchobby/esp8266-upy/tree/master/FBGFX/lib)
* [FBGFX/lib-optional](https://github.com/mchobby/esp8266-upy/tree/master/FBGFX/lib-optional)

Il suffit de copier ces fichiers dans le répertoire `lib/` sur votre carte MicroPython
