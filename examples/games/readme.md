Le répertoire __examples/games/__ contient de nombreux examples de jeu. 

__[racer/racer.py](racer/racer.py)__ : jeu de course. Voir le [readme du jeu](racer/readme.md).

![jeu racer](racer/docs/racer-01-lowres.jpg)

__[flappy/flappy.py](flappy/flappy.py)__ : adaptation du jeu Ardu Flappy (un clone de flappy bird).Voir le [readme du jeu](flappy/readme.md).

![jeu flappy](flappy/docs/flappy-00.jpg)

__[memory/memory.py](memory/memory.py)__ : Un jeu "Memory" pas si simple qu'il n'y parait! Voir le [readme du jeu](memory/readme.md).

![jeu memory](memory/docs/memory-03.jpg)

__[conway/conway.py](conway/conway.py)__ : Implementation du jeu de la vie pour Pico-Oled-Boot (dalle de 88x44). Existe aussi sous la forme 30x30 avec [games/conway/conwaysmall.py](examples/games/conway/conwaysmall.py). Voir le [readme du jeu](memory/readme.md).

![Game of Life](conway/docs/conway-01.jpg)

__[tetris/tetris.py](tetris/tetris.py)__ : Implementation du jeu Tetris pour Pico-Oled-Boot. Voir le [readme du jeu](tetris/readme.md).

![Jeu Tetris](tetris/docs/tetris-02.jpg)

__[labyrinth/labyrinth.py](labyrinth/micropython/labyrinth.py)__ : Jeu de Labyrinthe avec éditeur de niveau (et instructions) pour Pico-Oled-Boot. Voir le [readme du jeu](labyrinth/readme.md).

![Jeu Labyrinth](labyrinth/docs/labyrinth-interface.jpg)

__[breakout/breakout.py](breakout/breakout.py)__ : Jeu casse-brique de type Breakout pour Pico-Oled-Boot. Voir le [readme du jeu](breakout/readme.md).

![Jeu breakout](breakout/docs/breakout.jpg)

__[dino/dino.py](dino/dino.py)__ : Jeu Dino pour Pico-Oled-Boot en version simplifiée. Voir le [readme du jeu](dino/readme.md).

![Jeu Dino](dino/docs/dino.jpg)

__[invaders/invaders.py](invaders/invaders.py)__ : Jeu Space Invaders pour Pico-Oled-Boot. Voir le [readme du jeu](invaders/readme.md).

![Jeu Space-Invaders](invaders/docs/invaders.jpg)

__[dotman/dotman.py](dotman/dotman.py)__ : Collectez les points avant que le fantome ne vous attrape. C'est un peu un PacMan sans labyrinthe. Voir le [readme du jeu](dotman/readme.md).

![Jeu dotman](dotman/docs/dotman.jpg)

__[astroid/astroid.py](astroid/astroid.py)__ : Eviter les astéroides aussi longtemps que possible! Voir le [readme du jeu](astroid/readme.md).

![Jeu Astroid](astroid/docs/astroid.jpg)

__[tank/tank.py](tank/tank.py)__ : Petite bataille de tank! Voir le [readme du jeu](tank/readme.md).

![Jeu Tank](tank/docs/tank.jpg)

__[snake/snake.py](snake/snake.py)__ : Une implémentation originale du jeu Snake! Voir le [readme du jeu](snake/readme.md).

![Jeu Snake](snake/docs/snake.jpg)

__[minesweeper/minesweeper.py](minesweeper/minesweeper.py)__ : Une implémentation du jeu du démineur! Voir le [readme du jeu](minesweeper/readme.md).

![Jeu du démineur](minesweeper/docs/minesweeper.jpg)
