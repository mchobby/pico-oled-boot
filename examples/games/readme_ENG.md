The folder __example/games/__ contains many game examples.

__[racer/racer.py](racer/racer.py)__ : jeu de course

![jeu racer](racer/docs/racer-01-lowres.jpg)

__[flappy/flappy.py](flappy/flappy.py)__ : Ardu Flappy game adapted to MicroPython (a flappy bird clone alike)

![jeu flappy](flappy/docs/flappy-00.jpg)

__[memory/memory.py](memory/memory.py)__ : The "Memory" game not as simple as it may look at first sight!

![memory game](memory/docs/memory-03.jpg)

__[conway/conway.py](conway/conway.py)__ : Implementation of the Conway game of life for Pico-Oled-Boot (area of 88x44). Also exists with 30x30 area with  [conway/conwaysmall.py](conway/conwaysmall.py)

![Game of Life](conway/docs/conway-01.jpg)

__[tetris/tetris.py](tetris/tetris.py)__ : Implementation of the Tetris game for Pico-Oled-Boot.

![Tetris Game](tetris/docs/tetris-02.jpg)

__[labyrinth/labyrinth.py](labyrinth/micropython/labyrinth.py)__ : Labyrinth game with Level Editing instruction for Pico-Oled-Boot.

![Jeu Labyrinth](labyrinth/docs/labyrinth-interface.jpg)

__[breakout/breakout.py](breakout/breakout.py)__ : brick-breaker game like Breakout for the Pico-Oled-Boot.

![Breakout game](breakout/docs/breakout.jpg)
