# RobotEyes for Pico-Oled-Boot

RoboEyes uses the FrameBuffer to draw and animate eyes on the screen.

Roboyes for Pico-Oled-Boot do have examples script in the [examples/roboeyes/](examples/roboyeyes/) .

# Examples

* __[roboeyes_basic.py](roboeyes_basic.py)__ : basic script showing how to organise RoboEyes code.
* __[roboeyes_interactive.py](roboeyes_interactive.py)__ : script using the joystick to modify RoboEyes features.
* __[roboeyes_sequence.py](roboeyes_sequence.py)__ : script demonstrating animation sequence for RoboEyes.


# Documentation

The library and its documenation are available at [micropython-roboeyes](https://github.com/mchobby/micropython-roboeyes) repository.
