# Pico-Oled-Boot and FBGFX Fonts

Thank to the FBGFX library included within Pico-Oled-Boot, your script can load
alternative Font then draw text with the FBGFX FBText class.

This folder contains examples scripts showing how to load and use such Fonts.

More Fonts can be retreived from FBGFX library:

* [FBGFX/lib](https://github.com/mchobby/esp8266-upy/tree/master/FBGFX/lib)
* [FBGFX/lib-optional](https://github.com/mchobby/esp8266-upy/tree/master/FBGFX/lib-optional)

Then copy the downloaded file into the `lib/` subfolder of your MicroPython board.
